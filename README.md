# SPI WEB Test System - v2.0.0 (Final CBT Edition)

学生向けのCBT（Computer Based Testing）をWeb上で受験・管理できる、直感的なテストプラットフォームです。

先生方は専用のCSVファイルをアップロードするだけで簡単にテストを作成でき、学生はブラウザ上でスムーズに受験を進めることができます。
テスト終了後は、AIとグラフが受験結果を即座に分析します。

## 主な機能

### 先生・管理者向け機能
- 簡単テスト作成: 指定のCSV形式（問題文・選択肢・正答・配点など）を用意するだけで、オリジナルのテストを簡単に作成できます。
- クラス別のテスト配信: テストをアップロードする際、対象となるクラスを指定して配信できます。学生は自分に割り当てられたテストのみを受験可能です。
- リアルタイムな結果管理: 管理画面から、学生の受験結果（点数・正答率など）を一覧で確認できます。
- データの完全削除: 不要になったテストデータや結果は、管理画面から安全にすべて削除することが可能です。

### 学生向け機能
- 直感的な受験画面: Webブラウザ上で、スムーズにテストを受験できます。
- 即時の結果確認: テスト提出後、すぐに自身の点数や正答率を確認できます。
- AIによる個別フィードバック: Gemini AIが受験結果を分析し、学生一人ひとりに合わせた温かみのあるアドバイスや強み・弱みのフィードバックを生成します。
- 視覚的な結果分析: カテゴリ別の得点がグラフ（レーダーチャート等）で表示され、自分の得意・不得意分野をひと目で把握できます。

## セキュリティとデータ管理
本システムは、教育機関での運用を前提とし、以下のセキュリティ対策を施しています。

- アクセス制御: ログインできるユーザーは、本システムの学生および担当教師のみに制限されています。権限（ロール）に応じた厳格なアクセス管理を行っています。
- データベースの隔離: データベースは安全な環境に隔離されており、外部からの不正アクセスを防ぐ構成となっています。
- 認証情報の保護: ユーザーのパスワードは平文ではなく、安全なハッシュアルゴリズム（SHA-256）を用いてハッシュ化した状態でデータベースに保存されます。

## 技術スタックと柔軟なインフラ設計
- バックエンド: Python 3.11 / Flask
- AIエンジン: Google Gemini API (gemini-2.5-flash)
- データベース: PostgreSQL
- インフラ: Render (Web Service)

### インフラ・DBの移行性について
本システムは特定のインフラ環境に強く依存しない構成となっております。
今後の運用状況や要件に応じてインフラの変更を行う可能性があり、それに伴いデータベースの移行も想定しています。
ただし、移行先のサーバー環境においてPostgreSQLが使用可能であれば、本システムのコードを変更することなくそのままデータベースとして使用し、運用を継続することが可能です。

## 使い方（クイックスタート）

### 1. 先生（管理者）の操作
1. 先生アカウントでログインします。
2. 管理画面から、規定のCSV形式で作成したテストファイルをアップロードします。
3. テスト名、対象クラス、制限時間を設定して登録します。

### 2. 学生の操作
1. 学生アカウントでログインします。
2. ダッシュボードに表示された、自分に割り当てられたテストを選択します。
3. 制限時間内に解答を進め、テストを提出します。
4. 提出後、すぐに得点とAIからのアドバイス、分析グラフが表示されます。
